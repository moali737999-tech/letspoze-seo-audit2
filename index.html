Still open

unchanged since the third audit, ordered by severity
High

Page body is still built in the browser

The raw HTML is still about 4–5 KB per route: head tags only, no <h1> or body text server-side. Crawlers and AI bots that don't run JavaScript read the title and description but none of the page content.

Fix: extend the existing prerender step to include the page body, or server-render the routes.
Medium

Schema is still thinner than it could be

All 28 pages still resolve to the same four types: Organization, BreadcrumbList, ListItem, and Service on service pages. No Article/BlogPosting on the three blog posts, and no LocalBusiness entry with the Riyadh and Jeddah offices.

Fix: add BlogPosting to posts and office locations to the organization schema.
Low

Four titles and descriptions still run long

Homepage title 67 characters, /about title 72 (aim for ≤60). Petromin case-study description 190 characters, Digital City 166 (aim for ≤160). Not changed since the last audit.

Fix: tighten those four strings.
Low

No llms.txt

The URL still returns 404. Optional and ignored by Google, but some AI tools read it.

Fix: add a short plain-text llms.txt if AI visibility matters to you.
Medium

No Arabic version of the core site

The main site is English only; the only Arabic page is the seasonal campaign. For a Saudi-first brand this is a market-reach gap rather than a bug.

Fix: decide whether to build a full Arabic version.
