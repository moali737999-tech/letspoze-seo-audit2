Still open

ordered by severity
Critical

20 sitemap pages still hang on "Loading…"

/services and all 12 service pages, the 6 case-study detail pages, and /blog return 200 but never render content in the crawl (40-second timeout). This is now the entire services section — the pages that sell the product.

Fix: compare what /about and /case-studies do differently from /services, since those now load. Check the data loader behind the services and case-study detail routes for a slow or failing request.
High

No title or description in the server-sent HTML

The raw HTML still contains only a shell with a comment saying the head is managed client-side. Crawlers and social previews that don't run JavaScript see no title or description on any route.

Fix: pre-render or server-render the head tags per route, or add static defaults to the HTML shell.
High

/llms.txt returns the site shell, not a file

The URL answers 200 with the SPA's HTML, so AI crawlers get no real guidance file.

Fix: serve a plain-text llms.txt or return 404.
Medium

No HSTS header

The HTTPS response still lacks Strict-Transport-Security.

Fix: add max-age=31536000; includeSubDomains.
Medium

No Arabic version of the core site

The main site is English only; the only Arabic page is the seasonal campaign. For a Saudi-first brand this is a market-reach gap rather than a bug.

Fix: decide whether to build a full Arabic version.
Low

Generic alt="brand" on partner logos

Not re-checked in this pass; assume still open.

Fix: descriptive alt text per logo.
