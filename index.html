Fixed since the last audit

verified in this pass
Fixed

Page body now in the server HTML

Raw HTML per route grew from about 4 KB (head only) to 46–90 KB and now contains the <h1>, seven <h2> and twenty <h3> elements on the homepage, plus 26 internal links. Crawlers and AI bots that skip JavaScript can now read the content.

Fixed

BlogPosting schema on blog posts

All 4 posts now carry BlogPosting (with headline, description, URL and WebPage entity).

Fixed

Riyadh and Jeddah offices in schema

The Organization block on all 29 pages now lists two Place entries with PostalAddress (Riyadh and Jeddah, SA), plus the Instagram, TikTok and LinkedIn profiles.

Fixed

Title and description lengths

Homepage and /about titles are now 59 characters (were 67 and 72); the Petromin and Digital City descriptions are 155 and 142 (were 190 and 166). No page exceeds 60 for titles or 160 for descriptions.

Fixed

llms.txt

/llms.txt is now a real text/plain file describing the company, main pages, three featured services and the sitemap.

Added

New blog post in the sitemap

/blog/roaming-photo-booth-experience-for-events-and-parties was published and is in the 29-URL sitemap with the same head tags and schema as the other posts.

Still open

ordered by severity
Medium

Pages can hang on "Loading…" under parallel load

With three pages requested at once, 7 of 29 stayed on the loading screen in a real browser; the same pages rendered fine one at a time. The server HTML is complete either way, so crawlers that read raw HTML are unaffected, but a browser-based crawler could see an empty page.

Fix: check whether the host rate-limits parallel requests, and whether the client app can fail to start after hydrating the prerendered page. Re-test with a few pages at a time.
Low

/blog loses its canonical tag after the page runs

The raw HTML for /blog has <link rel="canonical">, but the rendered DOM has none (the other 28 pages keep theirs). Google's rendered snapshot would miss it.

Fix: have the client head manager keep or re-add the canonical on the blog listing.
Low

Office schema is city-level only

The two Place entries name only the city and country — no street address, phone or opening hours — and the type is Organization, not LocalBusiness. Case studies carry only Organization and BreadcrumbList.

Fix: add street addresses and a phone number for each office if you want local-pack visibility; consider LocalBusiness.
Medium

No Arabic version of the core site

The main site is English only; the only Arabic page is the seasonal campaign. For a Saudi-first brand this is a market-reach gap rather than a bug.

Fix: decide whether to build a full Arabic version.
Medium

No real performance or search data yet

There are still no Lighthouse or Core Web Vitals numbers, and no Google Search Console data on indexing and rankings, so the Performance score remains a placeholder.

Fix: connect Search Console and run PageSpeed Insights or Lighthouse.
